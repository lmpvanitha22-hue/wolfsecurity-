Always inspect the full domain before clicking. 📧 Urgent Email Requests Attackers create fake urgency — "Your account will be suspended!" Legitimate companies never demand immediate action via email links. 🔒 HTTPS Is Not Enough A padlock icon only means the connection is encrypted, NOT that the site is trustworthy. Phishing sites use HTTPS too. 📡 IP Address in URL URLs like http://192.168.1.1/login are a red flag. Real websites use domain names, not raw IP addresses. @ The "@" Trick A URL containing "@" redirects you to the part after it. http://safe.com@evil.com actually takes you to evil.com. 🧠 Think Before You Click When in doubt, navigate directly to the official website by typing the address yourself — never follow links in unsolicited messages.
